# CNCS · 校园网自动登录工具

> **Campus Network Connection System**
> 一个 AutoHotkey v2 小脚本：开机自动打开校园网客户端、填好账号密码、点掉弹窗。
> 断了自己重连，不用每次手动登录，也不用记密码。

**当前版本**：v1.21
**适用**：Dr.COM 类校园网客户端（需自行填写学校名，30 秒配好）
**其他学校**：改两行配置即可，见 `6-docs/适配其他校园网版本.txt`

**仓库**
- GitHub：https://github.com/SummerCalico/CNCS
- Gitee（国内镜像 / 完整版）：https://gitee.com/summer-tabby-cat/cncs

## 🚀 三步用起来

### 0. 先填你们学校的名字（30 秒，很关键）

公开发布版**没有**预填任何学校名（避免暴露作者就读学校），填一次就好：

1. 打开你的校园网客户端，看窗口**标题栏**上写的学校名
2. 记事本打开 `5-script/自动校园网.ahk`
3. 配置区找到 `ClientTitle  := ""`
4. 填进去：`ClientTitle := "你们学校名"`
5. 保存

> 不填也能跑（脚本退化为按进程名 + 「提示」类弹窗识别），填了抓窗口最稳。
> 客户端路径不对的话，顺便改上面那行 `ClientPath`。

---

### ① 装 AutoHotkey v2

双击 **`4-run/0-先装运行环境.bat`** —— 它会自动检测，没装就用 `7-runtime/` 里的官方安装包装上。

> 本包已自带官方安装包：`AutoHotkey_2.0.31_setup.exe`

**如果你的包是从 GitHub / Gitee 下载的**，那 `7-runtime/` 是空的——云端版不含安装包（约 3MB，官网本来就有，不必占仓库）。两种办法：

| 情况 | 怎么做 |
|---|---|
| **推荐**：直接下本地版 | 👉 **[Gitee 仓库](https://gitee.com/summer-tabby-cat/cncs)** 拿完整版，含运行环境，解压即用，**全程不用联网**，国内下载也快 |
| 能顺利上外网 | 去 [autohotkey.com](https://www.autohotkey.com/) 下一个 v2 安装包，拖进 `7-runtime/`，再双击 `4-run/补回运行环境.bat` 确认放好 |

> 想把这个包【转发给同学】，先确认 `7-runtime/` 里有运行环境，否则对方装不了。

### ② 填账号密码

打开 `5-script/自动校园网.ahk`，按 **`Ctrl+Alt+F7`** 填你的校园网账号密码。

> 密码明文存在 `5-script/account.ini`，**转发给别人前务必删掉它**。

### ③ 建快捷方式

双击 `4-run/一键配置.bat`，桌面快捷方式和开机自启就都建好了。

然后按 **`Ctrl+Alt+F9`**，客户端就出来了。

## 🧠 长期工作模式

这是本工具**唯一的工作方式**，规则只有三条：

| 你的操作 | 下次开机 |
|---|---|
| 按过一次 `Ctrl+Alt+F9`（用过） | **自动打开**，一个键都不用按 |
| 主动关掉了它 | **弹小窗问你**：打开 / 暂不 |
| 弹窗点了「打开」 | 恢复自动，回到第一条 |

**直接关掉客户端窗口也算数** —— 脚本会观察 45 秒（避开客户端自己更新时的短暂消失），确认是你关的后就**不再自动拉起**，想用按 `Ctrl+Alt+F9` 即可。

> 之所以给 45 秒宽限：客户端自己更新/重启时会短暂消失，不观察就判定会把正常重启误当成"你关了"。

## ⌨️ 为什么用组合键而不是 F7 / F9

Windows 的全局热键是**独占**的：谁先启动谁占住，后启动的那个**按了完全没反应，还不报错**。

游戏辅助工具（BetterGI 等）常把 `F6~F12` 整段注册成全局热键。用 `Ctrl+Alt+F7/F9` 基本没人占，跟任何工具都不打架。

## ❓ 杀毒软件报警？

**是误报，不是病毒。**

AutoHotkey 脚本能模拟键鼠、操作窗口、开机自启——这些能力和木马的技术路线重合，杀软看不到「目的」，只能看「能力」，所以先拦了再说。

**本工具 100% 开源文本**，用记事本打开 `自动校园网.ahk` 就能逐行检查。它没有联网、没有隐藏代码、不碰系统文件。

> 也正因为如此，本工具**不提供也不编译 EXE** —— 编译会把解释器+脚本打包成二进制，与部分恶意软件的打包手法相同，误报率大幅上升。

详见 `1-manual/杀软报毒说明.txt`（附图片版，方便直接发群）。

## ⚠️ 注意事项

- **不提供 exe**：只以 `.ahk` 源码分发，连编译指令都移除了
- **转发前删密码**：`5-script/account.ini`（账号密码）、`5-script/cncs.id`（你电脑的路径）
- **换学校**：改脚本里 `ClientPath`（客户端路径）和 `ClientTitle`（窗口标题里的学校名）两处
